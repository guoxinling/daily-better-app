# Daily Better GitHub Pages

This folder is ready to publish with GitHub Pages.

## Files
- `index.html`
- `support.html`
- `privacy.html`
- `.nojekyll`

## Easiest publish path
1. Create a new GitHub repository, for example `daily-better-site`.
2. Upload all files from this folder to the root of that repository.
3. Open the repository on GitHub.
4. Go to `Settings > Pages`.
5. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Save and wait a minute for GitHub Pages to publish.

## Your final URLs will look like
- `https://<your-github-username>.github.io/daily-better-site/`
- `https://<your-github-username>.github.io/daily-better-site/support.html`
- `https://<your-github-username>.github.io/daily-better-site/privacy.html`

## What to paste into App Store Connect
- Support URL: the `support.html` link
- Privacy Policy URL: the `privacy.html` link

## Before submission
- Open both links in an incognito window
- Confirm they load without login
- Confirm the email address is correct
- Confirm the pages work on mobile
