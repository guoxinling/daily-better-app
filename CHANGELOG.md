# Changelog

All notable changes to `Daily Better` will be documented in this file.

## [1.0.0] - 2026-03-23

### Added
- First public release of Daily Better.
- Today tab with a rotating daily affirmation and emoji mood check-in.
- Mood history review screen.
- Library for built-in, favorite, and custom affirmations.
- Settings for theme, text size, and a daily local reminder.
- App Store assets, privacy policy, and support pages.
